# Mollie Terminal for WooCommerce 0.5.3

Fixes a regression introduced in 0.5.1 that locked POS-only shops out of taking payments, and corrects the settings label that suggested the POS needed the WooCommerce checkbox.

## Fixed

- **POS payments were refused when the WooCommerce → Payments checkbox was off.** The 0.5.1 guard treated that checkbox as the only gateway switch, but WooCommerce POS enables gateways from POS → Settings → Checkout and ignores the WooCommerce one. Every POS-only setup, which is the recommended configuration, got "Mollie Terminal is disabled." when starting a payment or listing terminals. The guard now honours either switch: a gateway enabled in WooCommerce or in WooCommerce POS can take payments, and one switched off in both places is still refused.
- **Settings label corrected.** The Enable/Disable checkbox now reads "Enable Mollie Terminal for web checkout (not necessary for WooCommerce POS)", with a description explaining that the POS switch lives under POS → Settings → Checkout. This matches the other WCPOS terminal plugins.

## Upgrade

No configuration changes are required. If you ticked the WooCommerce checkbox as a workaround and do not sell online, you can untick it again; the POS keeps working from its own setting.
