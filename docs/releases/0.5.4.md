# Mollie Terminal for WooCommerce 0.5.4

## Fixed

- **Duplicate WooCommerce refund records.** Refunds now reuse the matching refund record WooCommerce just created instead of creating a second record and double-counting the refunded total. If no matching record exists, the request is rejected without contacting Mollie. Existing duplicate records are not changed by this update.

## Upgrade

No configuration changes are required.
