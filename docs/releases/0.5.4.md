# Mollie Terminal for WooCommerce 0.5.4

## Fixed

- **Duplicate WooCommerce refund records.** Refunds now reuse the refund record WooCommerce just created, captured from the `woocommerce_create_refund` hook so the gateway is bound to the exact record of its request, instead of creating a second record and double-counting the refunded total. If no record can be identified, the request is rejected without contacting Mollie. Existing duplicate records are not changed by this update.

## Upgrade

No configuration changes are required.
