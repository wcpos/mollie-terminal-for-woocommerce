# Mollie Terminal for WooCommerce 0.5.2

Fixes the first thing the beta tester saw after enabling QR payments in 0.5.0.

## Fixed

- **The QR code is now a proper square.** In the POS checkout the QR rendered as a thin strip next to its caption; opening the image in a new tab showed the full code, so only the layout was wrong. WooCommerce and POS themes style `img` inside the payment box for small method icons (inline, floated, height-capped), and those rules were overriding the image size. The QR is now pinned as a 240px square block with a centred caption below it, independent of theme CSS.

## Upgrade

No configuration changes are required. Hard-refresh the POS once so the new stylesheet loads.
