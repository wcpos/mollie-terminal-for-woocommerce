# Mollie Terminal for WooCommerce 0.5.1

A small follow-up to 0.5.0 closing a gap found during its review (#12).

## Fixed

- **Disabled means disabled.** Starting a payment and listing terminals now refuse with HTTP 403 when the gateway is switched off in WooCommerce → Payments. Before, they only checked the order token, so a cashier, or anyone holding a still-valid token, could start a Mollie payment for an unpaid order after the merchant had disabled the gateway.
- Poll, cancel and the Mollie webhook are deliberately untouched: a payment that was already in flight when the gateway was disabled still settles, and the cashier can still cancel it from the panel.
- Release notes are no longer hard-wrapped, so they render as paragraphs on GitHub releases.

## Upgrade

No configuration changes are required.
