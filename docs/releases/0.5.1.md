# Mollie Terminal for WooCommerce 0.5.1

A small follow-up to 0.5.0 closing a gap found during its review (#12).

## Fixed

- **Disabled means disabled.** The checkout actions the POS panel calls
  (start, poll, cancel, list terminals) now refuse with HTTP 403 when the
  gateway is switched off in WooCommerce → Payments. Before, they only checked
  the order token, so a cashier, or anyone holding a still-valid token, could
  start a Mollie payment for an unpaid order after the merchant had disabled
  the gateway.
- The Mollie webhook is deliberately untouched: a payment that was already in
  flight when the gateway was disabled still settles and completes its order.

## Upgrade

No configuration changes are required.
